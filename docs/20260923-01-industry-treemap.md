# 20260923-01 · 行业模型改为全板块热力图（面积 = 市值，颜色 = 涨跌，点击看细节）

## 背景与需求

用户反馈：行业模型区（「行业内如何定价 · 盈利 / 估值 / 情绪三要素」）不应
只看单个板块——**所有行业都要显示出来，按比例显示方块大小（红涨绿跌），点
击弹窗看具体细节**。经确认：

1. 方块**面积 ∝ 总市值**（东财板块口径，市场地图标准）；
2. 颜色**红涨绿跌、深浅随幅度**；
3. 点击弹窗**沿用现有全套详情**（换手 / 资金 / 市值 / PE 分位、120 日走势、
   成分股 TOP10、记录决策 / 交给对话解析）。

## 现状与问题（代码核对）

- `IndustryPanel`：左侧搜索框（TOP100 板块）+ 右侧单板块详情内嵌展示；
  一屏只能看一个行业，无法横向比较体量与涨跌分布。

## 设计

### 1. 数据与布局

- 数据沿用快照 `data.boards`（东财细分行业 TOP100，按市值去重；字段含
  涨跌 / 换手 / 主力净流入 / 市值 / PE），不新增网络请求；
- 布局用**squarified treemap**（纯函数）：输入各项面积（市值）与画布尺寸，
  输出无重叠、尽量接近正方形的矩形；
- 市值缺失的板块按「最小正市值 × 0.25」给一个可见的小方块（不隐藏行业）。

### 2. 视觉

- 画布：整宽 × 380px，容器 1px 圆角留缝；
- 颜色：红涨绿跌四档透明度（`/10 /25 /40 /60`，按 |涨跌幅| 分档），
  平盘或不详用中性底色；
- 标签：方块足够大时显示行业名（与涨跌幅）；小方块只留悬停提示
  （名称 / 涨跌 / 市值）——保证「所有行业可见、大行业可读」；
- 悬停加亮边框；点击打开详情弹窗。

### 3. 弹窗（IndustryDialog）

- 头部：板块名 + 代码 + 涨跌幅；
- 指标 5 格：换手率 / 主力净流入 / 总市值 / 板块 PE（TOP100 分位）/ 成分股
  PE·PB 中位；
- 120 日走势（Sparkline，沿用现有组件）；成分股 TOP10 表（市值 / 涨跌 /
  PE / PB）；
- 动作：记录决策、交给对话解析（沿用 `buildIndustryPrompt`）；
- 加载中显示骨架；Esc / 点击遮罩关闭。

## 风险与边界

- 东财板块为 TOP100 按市值抓取，非全市场行业全集；「所有行业」指当前
  板块集合（约 86 个去重后），市值缺失者给可见小方块；
- 热力图只做行情与体量表达，不引入评分（评分属于中证 / 申万两张轮动表）；
- 列表搜索框移除：热力图 + 标签即可定位；如需按名称检索可后续再加；
- 不新增网络请求（详情仍按点击按需拉取，缓存 5 分钟）。
