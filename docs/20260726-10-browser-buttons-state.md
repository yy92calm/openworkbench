# 浏览器面板按钮状态可视化

## 背景

`BrowserPanel` 的录制 / 停止 / 保存 / 回放等按钮均为小图标（`p-1`、`size=13`），hover 反馈弱；录制中仅 `opacity-40`，回放中仅 `disabled`，运行状态不明显，用户难以区分可点击与运行中。

## 设计

- **录制 / 停止合并为切换按钮**：未录制 = 红边框 + 「录制」文字；录制中 = 红底白字 + 脉冲 + 「停止 N」（N 为已录步数）。
- **保存按钮**：加「保存」文字 + 边框，`disabled` 态明确（录制中或无录制时）。
- **回放按钮**：加「回放」文字；回放中显示旋转图标 + 禁用，回放列表在回放中不弹出。
- **控制台按钮**：激活态 `bg-accent/10` 高亮。
- 按钮统一 `rounded-input` + 边框，hover/active 有背景反馈，点击区与运行态一眼可辨。

### 不做

- 不改 webview、URL 导航、JS 执行逻辑。
- 不改控制台/保存输入框布局。
