## 设计

### 1. 顶部结论区：建议动作 + 变化（免点击读完）

- shared 新增纯函数 `buildMacroConclusion(snapshot) → { action, change }`：
  - `action`：`建议超配：A、B；建议低配：C。`——**全量名单、不截断**，
    某侧为空显示「暂无」；
  - `change`：`较上一交易日：X 走强、Y 走弱。`——取当日评分变化最大的
    上升 / 下降各一名，只讲方向；幅度仍在轮动表「评分」旁的变化值
    （脚注口径不变）；无变化时为 `null`；
  - 数据未就绪沿用「数据加载中 / 历史数据不足」文案，`change = null`。
- `buildMacroSummarySentence` 改为 `action + change` 拼接：导出汇报 /
  复制摘要 / prompt 沿用同一入口，口径一致。
- 页面渲染两行：结论行（13px medium）+ 变化行（12px muted），替代原
  单行摘要句。
- 轮动表保持按评分降序（最强在前）、变化值就近可见，作为结论的证据。

### 2. 操作收敛：阅读态只留页面级三键，研究操作悬停显现

- 原则：常驻操作 = 刷新 / 导出（复制 · 导出 · 打印）/ 通知；其余研究操作
  **默认隐藏、悬停所属区域时显现**，复用本页已有的悬停模式（轮动表
  「记录决策」、指标卡「引用」），不新增菜单实体、不移动操作上下文。
- 落点：

  | 区域 | 操作 | 处理 |
  | --- | --- | --- |
  | 数据底座折叠行 | 引用核心指标 | 悬停显现（展开后各分区的「引用本组」保持常驻） |
  | 轮动模型标题行 | 设为工作日任务 / 生成轮动周报 | 悬停显现 |
  | 行业面板标题行 | 记录决策 / 生成行业定价分析 | 悬停显现（选中行业后才渲染） |
  | 决策台账标题行 | 筛选 / 导出 CSV / 复盘与再训练 | 悬停显现 |
  | 决策台账行内 | 归因 / 编辑 / 删除 | 悬停显现（归因结果文案仍常驻行内） |

- 打印：隐藏控件不进入打印；复制 / 导出 Markdown 内容不受影响。

## 风险与边界

- 「走强 / 走弱」是方向口径（评分变化最大者）；幅度看轮动表，摘要不重复
  数字，避免把 0–100 评分解释负担带进结论句。
- 悬停显现沿用本页既有交互模式（键盘 Tab 不可达、无悬停设备不可见）；
  研究功能全部保留，仅可见性变化。若后续需要，可再加常驻的「研究操作」
  入口。
- 不涉及主进程、IPC、数据抓取与提示词；行业模型仍需先选行业才能看
  明细（未在本次范围内）。
