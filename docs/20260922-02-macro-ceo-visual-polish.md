# 20260922-02 · 宏观洞察 CEO 展示风格（结论 + 视觉化）

## 背景与需求

用户反馈：优化显示风格，面向 CEO 查看。经确认：

- 范围：**整个宏观洞察页**（重点为申万全景表与轮动表）；
- 方向：**结论 + 视觉化**——区块顶部给一句直接结论；表格用评分条、
  占比条、涨跌色块；信号分组分隔；次要列降噪。

## 现状与问题（代码核对）

| # | 区域 | 问题 |
| --- | --- | --- |
| 1 | 申万全景表 | 31 行 × 9 列纯数字，无视觉编码；需要读者逐行读数字才能看出强弱与资金集中 |
| 2 | 申万区块 | 没有结论句：CEO 要在 31 行里自己找「谁最强、谁最弱、钱在哪」 |
| 3 | 轮动表 | 评分只有数字；趋势「线上 / 线下」是纯文本，扫描成本高 |
| 4 | 决策台账 | 归因率是文字，缺少「闭环推进」的直观状态 |
| 5 | 全局 | 主次信息字号层级不清（大量 11px / 12px 同级并列） |

## 设计

### 1. 申万区块：结论先行 + 视觉编码

- 区块顶部新增结论两行（与概览口径一致的主次层级）：

  - 结论行（13px medium）：
    `评分领先：电子 88、电力设备 76、计算机 71；评分垫底：房地产 18、银行 24。`
  - 补充行（12px muted）：`成交聚焦：电子 28.5%、医药生物 7.3%。`

  由 shared 纯函数 `buildSwConclusion(rows)` 生成（可测），口径：
  评分前 3 / 后 3；成交额占比前 2（实时口径）。
- 表格视觉化：
  - **评分列**：0–100 进度条（配色随信号：超配红 / 中性灰 / 低配绿）+
    分值 + 较上一交易日；
  - **成交额占比列**：按行内最大值归一化的迷你条 + 数值（资金聚焦一眼可见）；
  - **今日涨跌**：色块 chip（`rise/5` / `fall/5` 底 + 语义色文本）；
  - **信号分组**：按超配 / 中性 / 低配 / 未评分插入分隔行（组名 + 数量 +
    细分隔线），行序沿用评分降序；
  - **次要列降噪**：成交额占比 / 换手 / PE / 股息 / 60 日 → 11–12px muted，
    行业与评分保持 13px 主级。

### 2. 轮动表：同一套视觉语言

- 评分列加同款比例条（超配红 / 中性灰 / 低配绿）；
- 趋势列改为「语义色圆点 + 文字」（20 日线上红点 / 线下绿点），
  其余列维持现状（上一轮已降噪）。

### 3. 决策台账：闭环状态可视

- 统计行「已归因 x（y%）」后加一条迷你进度条（accent/60），
  直观呈现归因闭环推进度。

### 4. 全局层级

- 区块标题维持 13px medium + 11px muted 说明；数字层级统一：
  主指标 13px、次要 11–12px muted、色块与条只用于主指标；
- 概览结论行（13px）与申万结论行样式对齐（同一视觉语法）。

## 风险与边界

- 视觉编码不新增信息、不删数据：所有数值仍在表内或弹窗可查；
- 分组分隔不改变行序（评分降序天然按信号连续分段），未评分行单列一组；
- 条与 chip 使用现有语义色（红涨绿跌、信号同色），不引入新色板；
- 打印与导出不受影响（导出内容为文本 Markdown）。
