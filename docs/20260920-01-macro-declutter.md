# 20260920-01 · 宏观洞察信息降噪（汇报可读性）

## 背景与需求

用户反馈「界面信息太乱」，范围确认为**整个宏观洞察页**。目标：

1. 同一信息只出现一次（当前摘要句、KPI、闭环步骤条三层重复）；
2. 次要信息渐进展开（数据底座、明细口径、筛选器不常驻）；
3. 首屏保持「领导检查」可读：模型与决策优先，数据底座退居折叠区。

## 现状乱源（代码核对）

| # | 乱源 | 说明 |
| --- | --- | --- |
| 1 | 同一组数字三处重复 | 摘要句、6 格 KPI、六步闭环 chips（超配/低配行业、台账条数、归因率、知识资产）各出现一遍 |
| 2 | 概览操作区 7 个按钮 | 引用核心指标 / 刷新 / 通知 / 复制摘要 / 导出摘要 / 打印 |
| 3 | 数据底座全量展开 | 9+7+5+2 张卡片 + 基金 TOP5 列表，占页面最大面积（约 23 卡） |
| 4 | 模型区口径文字压标题 | 轮动公式/高波动说明为标题行长句；资金流 10 个彩色 chips 常驻 |
| 5 | 行业面板 7 格 KPI + 长脚注 | 换手/资金/市值/板块 PE/分位/PE 中位/PB 中位同权重并列 |
| 6 | 台账筛选器常驻 | 3 组分段按钮 + 搜索框始终占一行 |

## 设计

### 1. 概览区（去重 + 收纳）

- **摘要句只保留轮动信号**：超配/低配行业 + 较上一交易日评分提升最多者；
  台账/归因/知识资产数字下沉到 KPI（`buildMacroSummarySentence` 签名单参
  化：`(snapshot)`，不再接收 decisions/digest；汇报 Markdown 同步受益）。
- **KPI 6 格 + 闭环 chips 行 → 5 格**：

  | KPI | 内容 |
  | --- | --- |
  | 行业覆盖 | N 指数 · M 板块 |
  | 轮动信号 | 超配 x · 中性 y · 低配 z |
  | 决策台账 | N 条（sub：归因率 x% · 待归因 k） |
  | 知识资产 | 约 X 字 / 待沉淀 |
  | 数据时效 | 6/6 源（sub：刷新中 / 公开数据源） |

  六步闭环不另起一行（其数字已分别落在 KPI 中）；闭环链路文字并入定位语，
  只出现一次。
- **操作区 7 → 3**：刷新（图标按钮，悬停提示）、导出下拉（复制汇报摘要 /
  导出 Markdown / 打印）、通知铃铛；「引用核心指标」移入数据底座折叠行。
- 定位两行 → 一行；灰字、11px。

### 2. 数据底座（整块折叠）

- 折叠行：`数据底座 · 模型输入` + 实时摘要（`6/6 源 · 上证 3808.52 +0.31%
  · 沪深300 4507.39 +1.06% · 中债 10Y 1.68% · USDCNH 6.6953`，缺失项自动
  省略）+「引用核心指标」+「展开 ▾」。
- 展开后四个分区照旧（各分区保留「引用本组」）；默认收起，会话内记忆
  （state，不落盘）。
- 刷新推送不受折叠影响（数据始终在后台更新）。

### 3. 模型区（口径下沉 + 资金流折叠）

- 轮动：公式、高波动、评分变化说明从标题行移到**表下脚注**（11px）；
  资金流 TOP10 默认折叠为一行纯文本「前 3：电子 +19.9亿 · 半导体 …」，
  「展开」后显示原有 chips。
- 行业面板：7 格 KPI → 5 格（换手率 / 主力净流入 / 总市值 /
  板块 PE（sub：TOP100 分位 x%） / 成分股 PE·PB 中位），脚注缩短。

### 4. 决策台账（筛选收纳）

- 筛选器（模型 / 状态 / 关键字）默认收起，header 放「筛选」按钮；有任一
  筛选生效时按钮高亮并可一键「清除」。
- 统计行缩短（去掉长路径，改为「工作区 decisions.jsonl」）。

### 5. 排版

- 分区间距 `mt-7 → mt-6`、分区内 `mt-5 → mt-4`；说明文字统一 11px muted。
- 打印：按当前折叠状态输出（复制 / 导出 Markdown 已含全量数据，不受折叠
  影响）；导出菜单（按钮 + 菜单）不参与打印。

## 风险与边界

- 数据底座默认折叠：日常盯盘用户需多点一次；折叠行提供关键指数摘要与
  「引用核心指标」以降低代价；不做持久化偏好（保持简单，若反馈强烈再加）。
- 打印按当前折叠状态输出：折叠区的数据不会进打印页；导出 Markdown /
  复制摘要始终包含全量（数据源状态、轮动表、台账）。
- 摘要句精简后，领导如需完整口径请看 KPI 行与导出的汇报 Markdown。
- 仅渲染层与 shared 纯函数调整，不涉及主进程与 IPC。
