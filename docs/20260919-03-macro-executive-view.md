# 20260919-03 · 宏观洞察汇报视图（面向领导检查）

## 背景与需求

「宏观洞察」需要面向领导检查：首屏即可读地呈现系统定位、运转状态与价值
证据（模型信号、决策/归因闭环、知识资产规模）。经确认：不做独立汇报模式，
**同一页面**在顶部新增「汇报概览区」，模型前置、数据底座后置；概览包含
全量 KPI + 动态摘要句 + 六步闭环实时数字。

## 设计

### 顶部汇报概览（顺序 1）

- 定位行：`宏观洞察` + 徽标「AI 投研系统 · 轮动模型 × 行业模型」+ 更新时间
  / 刷新 / 通知。
- 定位语：轮动模型回答何时配什么行业，行业模型回答行业内如何定价；
  数据 → 信号 → 模型 → 决策 → 归因 → 再训练闭环。
- **动态摘要句**（一句话汇报口径）：当期超配/低配行业 + 台账条数与归因率 +
  知识资产字数。
- **全量 KPI（6 格）**：

| KPI | 口径 |
| --- | --- |
| 行业覆盖 | 中证十行业指数数 + 东财板块数（去重后） |
| 轮动信号 | 超配 / 中性 / 低配计数（透明评分） |
| 决策台账 | 总条数 + 待归因数 |
| 归因率 | 已归因 / 总数（四舍五入） |
| 知识资产 | knowledge.md 去空白字符数；无则「待沉淀」 |
| 数据时效 | 就绪数据源 / 总数据源（6） |

- **闭环实时数字**：数据 `就绪/总`、信号 `条数`、模型 `2`、决策 `条数`、
  归因 `已归因 · %`、再训练 `知识资产字数 / 待沉淀`。

### 页面重排（模型前置）

用 flex order 实现结构重排，不改各区块内部实现：

```text
① 汇报概览（order-1）
② 轮动模型 · 何时配什么行业（order-2）
③ 行业模型 · 行业内如何定价（order-3）
④ 决策台账 · 记录 → 归因 → 再训练（order-4，统计头：总条数/归因数/归因率）
⑤ 数据底座 · 模型输入（order-5，原四分区，标题弱化并分组）
⑥ 免责声明（order-6）
```

### 其他细节

- 决策台账标题改为「决策台账 · 记录 → 归因 → 再训练」并带统计。
- 数据分区标题去掉「· 数据」后缀，统一收进「数据底座 · 模型输入」。
- 红涨绿跌、主题化（五套配色）保持不变。
