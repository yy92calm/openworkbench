# 终端 P0/P1 功能补齐

## 背景

右侧 dock 的终端面板（`apps/desktop/src/renderer/components/inspector/TerminalPanel.tsx` + `apps/desktop/src/main/terminal.ts`）当前只具备最骨架的能力：单个本地 shell、
xterm 渲染、链接点击、自适应尺寸、主题跟随。距"通用可用终端"还有明显缺口。

调研确认的事实：

- `packages/terminal/` 是与 `apps/desktop` 几乎重复的实现，但**无任何引用**
  （`registerTerminalHandlers` 来自 `apps/desktop/src/main/terminal.ts`，Panel
  来自 `apps/desktop/src/renderer/components/inspector/TerminalPanel.tsx`）。属
  历史遗留死代码，本次不动、不删，仅记录。
- 主进程 PTY 管理已按 `id` 做 Map（`sessions`），天然支持多会话，无需改主进程。
- 现有"审批"（`permission.asked` / `PermissionCard`）是 **agent 通道**专用，
  与用户在终端里手动敲命令是两条独立通道，语义不可直接混用。
- `WorkbenchDock` 里 terminal 是条件渲染（`tab === "terminal"` 才挂载），切走即
  卸载 xterm、cleanup 触发 `terminal:close` 杀掉 PTY——切回内容全丢。

## 设计

### 本次实现（6 项）

#### 1. 多会话/多标签（P0）

- `TerminalPanel` 由"单实例"升级为"标签容器 + 单实例视图"：
  - `TerminalPanel`（容器）：持有 `tabs: { id, shell, title }[]` 与 `activeId`，
    顶部渲染紧凑标签条（11px，标题 + 关闭 x）与右侧"+"新建按钮、shell 选择。
  - `TerminalView`（视图）：单个 xterm 实例，接收 `id/shell/onClose`，负责 PTY
    生命周期与渲染。
- 主进程无需改动（`sessions` Map 已按 id 多会话）。
- 关闭最后一个 tab 时调用外层 `onClose`（收起 dock）。
- 标签标题默认 `终端 N`，shell 切换后追加 shell 名（如 `zsh`）。
- 终端会话是辅助工具，不进 `runtime.ts` 的 per-session `PaneState`，状态留在
  `TerminalPanel` 组件内（in-memory），保持简单。

#### 2. 复制粘贴（P0）

- 选中复制：容器级 `keydown` 监听，macOS `Cmd+C` / Win/Linux `Ctrl+Shift+C`，
  有选区时 `navigator.clipboard.writeText(term.getSelection())`，无选区放行（不
  拦截浏览器默认）。
- 粘贴：macOS `Cmd+V` / Win/Linux `Ctrl+Shift+V`，`navigator.clipboard.readText()`
  后 `term.paste(text)`。
- 右键：有选区时复制，无选区时粘贴（贴近传统终端习惯）。
- 不引入额外 addon，仅用 `navigator.clipboard` + xterm 既有 API。

#### 3. 搜索（P0）

- 新增依赖 `@xterm/addon-search`（与现有 `@xterm/addon-fit` 同源、同版本节奏）。
- 视图顶部可折叠搜索条：`Cmd+F` 展开，输入即 `findNext`，`Shift+Enter` 反向，
  `Esc` 关闭。上一个/下一个按钮。
- 搜索条仅作用于当前活动 tab 的 xterm 实例。

#### 4. IME 中文输入（P0）

- xterm v6 通过隐藏 textarea 支持 IME，主要失效原因是失焦或 textarea 被遮挡。
- 修复点：tab 切换/打开时显式 `term.focus()`；构造时 `disableStdin: false`（默认）；
  确保容器不拦截 composition 事件。
- 不自造 IME 逻辑（易引入新 bug），以"聚焦正确 + 不阻断 composition"为目标，
  依赖 xterm 内建能力。

#### 5. 滚动缓冲可配 + 字号缩放（P1）

- `Terminal` 构造 `scrollback` 由默认 1000 提到 10000（通用门槛）。
- 字号：`Cmd+=` 放大、`Cmd+-` 缩小、`Cmd+0` 重置（13–20 范围夹紧），改
  `term.options.fontSize` 后 `fitAddon.fit()`。
- 字号持久化到 `localStorage`（`workbench.terminal.fontSize`），新 tab 继承。
- 不做设置面板（运行时不可配置原则），仅快捷键 + 合理默认。

#### 6. 会话保持（P1，原"会话恢复/重连"的轻量化）

- 痛点：切 tab 卸载 xterm → cleanup 杀 PTY → 切回全空。
- 方案：`WorkbenchDock` 把 terminal 改为**常驻 hidden**（参照 `BrowserPanel` 的
  `hidden` 而非条件渲染）。首次进入 terminal tab 才挂载，之后切走仅 `hidden`，
  xterm 实例与 PTY 都保留，切回内容自然还在。
- 不引入主进程输出 buffer / replay IPC——常驻 hidden 已覆盖用户态主痛点
  （切 tab 不丢）。开发期 HMR reload 仍会丢，属可接受的开发场景。
- 多 tab 下非活动 tab 的 xterm 也常驻 hidden，终端数量通常很少，性能可接受。

### 不做（划清边界，留作阶段二）

#### SSH 远程会话（P1-6）

- 接口已预留（`terminal:create` 的 `type: "local"|"ssh"`，当前被 `_type` 忽略）。
- 但完整实现需引入 `ssh2` 依赖、连接管理 UI（主机/端口/用户/密钥/密码）、跳板、
  断线重连，是独立大功能。本次**不实现**，仅保证接口不被破坏、不误导。
- 留作专项方案文档。

#### 危险命令审批集成（P1-7）

- 现有 `permission` 系统是 agent 通道专用（拦截 agent 发起的工具调用）；终端是
  用户**直接操作**通道，强行接入会造成两套语义混淆。
- 轻量"黑名单正则确认"（`rm -rf` / `dd` / `mkfs` 等）跨平台命令行解析易误判
  （管道、`&&`、引号、变量），误报漏报风险高，价值存疑。
- 需先定设计（是否做、做多重），留作专项。本次**不实现**。

### 实现要点

- 改动文件：
  - `apps/desktop/src/renderer/components/inspector/TerminalPanel.tsx`：拆分为
    `TerminalPanel`（容器）+ `TerminalView`（视图），加 tabs、复制粘贴、搜索条、
    字号缩放、IME 聚焦。
  - `apps/desktop/src/renderer/components/inspector/WorkbenchDock.tsx`：terminal
    改常驻 hidden。
  - `apps/desktop/package.json`：加 `@xterm/addon-search` 依赖。
- 主进程 `terminal.ts` 不改（多会话已支持）。
- `packages/terminal/` 死代码不动。
- 视觉沿用现有 CSS 变量与 `text-[11px]` 紧凑风格，不引入新设计 token。
- 复制粘贴/搜索/字号的快捷键监听挂在视图容器，`stopPropagation` 仅在命中时，
  避免污染全局。
