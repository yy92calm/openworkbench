# 隐私卡片两栏显示优化

## 背景

隐私与数据分组的 `DataFlowCard` 用 `sm:grid-cols-2` 双栏。`sm:` 断点基于视口宽度,在 1280px 窗口下设置页右栏内容宽仅约 432px,双栏后每栏约 206px,长句频繁换行;发送栏 model 标签与标题文字同处一行,空间不足时互相遮挡,整体不易看清。

## 设计

- **双栏改单栏堆叠**：`grid sm:grid-cols-2` -> `space-y-5`。本机块在上、发送块在下,各自占满右栏宽度,文字舒展不挤。
- **左侧色条区分**：本机块 `border-l-2 border-ok`（绿）、发送块 `border-l-2 border-warn`（黄）,一眼区分「留下」与「发出」。
- **model 标签换行友好**：发送栏标题行加 `flex-wrap`,空间不足时 model 标签自动换到下一行,不再挤压标题文字。
- 不改文案、不改 props、不改测试断言。
